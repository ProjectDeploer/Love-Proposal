# Love Proposal Website ❤️

A romantic, responsive, static proposal website built with HTML, CSS and JavaScript.

## Run locally

Open `index.html` in your browser, or use VS Code Live Server.

## Deploy on Vercel

1. Create a GitHub repository.
2. Upload all files in this folder.
3. In Vercel, click **Add New → Project**.
4. Import the GitHub repository.
5. Framework Preset: **Other** (or leave automatic detection).
6. Build Command: leave empty.
7. Output Directory: leave empty.
8. Click **Deploy**.

No environment variables or backend are required.

## Personalize

- Change the title and name in `index.html`.
- Edit the final letter in the `#final` section of `index.html`.
- Change questions and answers inside `questions` in `script.js`.
- Adjust colors and typography in `style.css`.
